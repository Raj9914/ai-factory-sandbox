# Product PRD
Specify the smallest coherent app/game that can be built, launched to beta and evaluated within 48 hours.

Required: problem/player need; target user/context; alternatives/evidence; value proposition; primary journey/game loop; must-have/out-of-scope; screens/states; data/integrations; privacy/security/accessibility; analytics; non-functional needs; testable acceptance criteria; launch/rollback; hour-24/hour-48 gates.

Default scope: one persona, one core journey, usually 3–5 app screens or one playable game loop. Exclude authentication, payments, social features and admin UI unless essential. Label facts, assumptions and open questions separately.

Write to docs/PRD.md in the product repository. Do not create issues unless requested. Acceptance criteria must be observable and testable.
