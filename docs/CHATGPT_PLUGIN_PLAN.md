# ChatGPT Skills / Plugin Plan

Canonical skill sources are in skills/; chatgpt-plugin/skills/ is a mirror, not an installed plugin.

When account/workspace supports it: use official ChatGPT skill/plugin creation UI; package selected instructions/resources; connect GitHub/Figma using supported integrations and narrow permissions; test supported Chat/Work surfaces; share privately first.

Feature eligibility varies by plan/workspace/role/surface. Verify actual account UI. A SKILL.md in GitHub does not auto-install into ChatGPT Web. Never scrape ChatGPT UI, reuse cookies, treat subscription as API credits or expose unrestricted shell/secret access.
