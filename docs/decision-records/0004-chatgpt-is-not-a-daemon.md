# ADR 0004 — ChatGPT Web Is Not a Daemon
- Status: Accepted
- Date: 2026-11-11

ChatGPT Web is an interactive product/design/review worker through supported apps and skills/plugins. An ordinary chat cannot be assumed to run continuously or wake from GitHub comments. Unattended OpenAI work needs eligible event capability or a separate authenticated API runtime. Subscription and API billing are separate.
