# 48-Hour Experiment

Clock starts when owner approves the idea and freezes MVP.

| Time | Goal | Evidence |
|---|---|---|
| 0–2h | Idea/access | Approved brief, audience, risks |
| 2–4h | PRD | Activation event, scope |
| 4–6h | Design | Screen matrix, Figma |
| 6–18h | Build | Core journey, tests, PR |
| 18–24h | Beta | URL, smoke test, analytics |
| 24–36h | Exposure | Target users, feedback |
| 36–42h | Fix | Critical fixes, regression |
| 42–48h | Decision | Evidence/cost report |

At hour 24, cut scope if core journey is not usable. At hour 48 choose CONTINUE, PIVOT, KILL or INCONCLUSIVE.

Define activation before launch. Record numerator, denominator, window and acquisition source. Games: meaningful sessions, loops completed, replay. Apps: primary task completion and return use. Small samples are directional only.

Initial internal hypotheses: app—10 relevant testers, 5 core completions, 3 return signals; game—20 meaningful sessions, 5 replays/share signals. Not industry benchmarks. Zero unresolved critical security/data-loss defects.
