# ChatGPT Web Playbook

When invoked: read playbook/task; confirm repo/branch/owner; read PRD/design; use connected GitHub/Figma tools within granted permissions; record evidence in issue/PR; report outcome and next owner.

ChatGPT role: idea research/score, PRD, UX/screen spec, Figma where connected, architecture/security assessment, independent PR review, experiment analysis.

Limits: this file does not install itself as a ChatGPT skill. GitHub comments do not wake an ordinary chat. App permissions and plan/workspace eligibility govern features. Subscription and API billing are separate. For unattended OpenAI use an explicit API worker or supported event capability; never scrape ChatGPT UI or reuse session cookies.

Canonical skills: skills/. Mirrors: .agents/skills/, .claude/skills/, chatgpt-plugin/skills/. Plugin folder is packaging source, not an installed plugin; verify account eligibility in actual UI.

Report completed work, changed links, verification, blockers/risks and next owner.
