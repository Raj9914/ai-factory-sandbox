# Research

Market, competitor and user research for this product. Start from `MARKET_RESEARCH_TEMPLATE.md`; save each study as `docs/research/<YYYY-MM-DD>-<topic>.md`.

Rules:
- Every claim has a source link and access date. Write `NOT FOUND` instead of guessing.
- Label statements **Fact** (source, date), **Assumption** or **Open question**.
- No personal data from interviews or forums; summarise and anonymise.
