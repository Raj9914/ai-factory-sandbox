# Idea Score
Evaluate evidence before novelty. Separate facts, assumptions and opinions. Never invent market data or user feedback.

Input: idea, target user, need/game loop, current alternative, distribution, scope, evidence and risks.
Score each 0–5 with reason: user need, audience reachability, differentiation, 48-hour feasibility, repeat-use, strategic value and measurability. Total /35 is an internal heuristic, not a market benchmark.

Verdicts: 26–35 BUILD candidate; 19–25 NARROW/VALIDATE; 0–18 KILL. Any serious legal, safety, privacy, security or affordability concern means STOP regardless of score.

Output: verdict, scores, confidence, target user, core action, activation event, smallest MVP, top risks, evidence gaps, hour-24/hour-48 criteria and next owner.
