# Screen Design
Figma is the editable design source of truth. GitHub stores requirements, flows, tokens/specs, Figma links, review exports and implementation.

Steps: read approved PRD; map primary flow; inventory screens/states; define tokens/components; create editable Figma frames; cover loading, empty, error, success, disabled and validation; define responsive/accessibility behaviour; record Figma URL, page, frame/node IDs and version in docs/design/README.md; provide implementation acceptance criteria.

Apps: home, core action, result/confirmation and essential onboarding/settings only. Games: title/start, play loop, pause/resume, result, restart/replay. Do not claim Figma work exists unless confirmed. PNGs are not editable source. Do not commit proprietary .fig files or unlicensed assets.
